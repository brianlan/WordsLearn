# 持久学习活动与媒介模式库

在用户要求非传统练习、软件、多模态活动或实际制品时使用。先选择学习机制，再让 App 或其他媒介承载该机制。

## 1. 媒介选择顺序

依次回答：

1. 学习者必须执行什么认知动作？
2. 该动作需要什么输入、反馈和状态？
3. 纸笔或口头活动是否已经足够？
4. 技术能否明显改善随机化、排程、自适应、记录、模拟或可访问性？
5. 技术成本是否会挤占真正练习时间？

只有第四项的收益明确时再增加技术复杂度。

## 2. 检索模式

- **空白纸回忆**：限定时间写出能回忆的全部内容，再对照资料补缺。
- **短答卡**：问题在正面，答案与错误解释在背面；先完整作答再翻面。
- **教给虚拟学生**：要求学习者解释概念，系统追问含糊处和缺失因果。
- **图像标注**：隐藏标签，让学习者在结构图、地图或几何图上定位并命名。
- **步骤重建**：打乱或隐藏程序步骤，让学习者排序、补全并解释理由。
- **情境回忆**：给出真实场景线索，让学习者回忆适用规则，而非直接说出规则名。
- **双向检索**：词到义、义到词；公式到用途、情境到公式；例子到概念、概念到例子。

## 3. 间隔与自适应模式

- **莱特纳盒**：答错回到高频盒；稳定答对进入低频盒，但不永久移除重要内容。
- **遗忘触发队列**：根据上次成功时间、信心和错误类型安排下一次出现。
- **累积小测**：每次同时包含本周内容、近期内容和较早内容。
- **会话重启题**：每次学习开始先闭卷回答上一次的关键问题。
- **月度保养**：对已经熟练但长期重要的知识安排低频复测。

自适应规则同时使用答案完整度、反应时间、信心、提示次数、错误类型和正确性。

## 4. 穿插与辨析模式

- **混合题池**：随机混合相近题型，要求先标注题型和选择依据，再求解。
- **最小对比对**：并列两个容易混淆的例子，要求指出决定性差异。
- **找异类**：给出多个样例，选择不属于同一概念的项目并解释。
- **错误解法诊断**：展示几个看似合理的解法，让学习者判断何处开始失效。
- **概念边界游戏**：连续给出正例、近邻反例和边界案例，逐步修正分类规则。
- **策略竞赛**：同一问题提供多种可选策略，要求根据条件选择而非机械执行。

## 5. 多样化与迁移模式

- **参数化变式生成器**：改变数值、表述和表面特征，同时保持目标结构。
- **多表征转换**：文字、图形、方程、表格、口头说明之间相互转换。
- **情境迁移**：把同一原理放入家庭、校园、工程或游戏等不同情境。
- **规则例外挑战**：加入原策略不再适用的条件，要求判断何时切换。
- **未知样例检验**：最终使用练习中未出现过的材料，测真正迁移。
- **渐进模拟**：从简化场景开始，逐步加入真实约束、干扰和时间压力。

## 6. 生成、细化与反思模式

- **讲解前预测**：先猜结果、公式、故事走向或实验现象，再观看讲解。
- **例题渐隐**：完整例题 → 隐去一步 → 隐去多步 → 独立完成。
- **为什么链**：对关键结论连续追问原因，直到抵达基础原理或证据。
- **自造例子与反例**：要求学习者各造一个，并说明决定性特征。
- **概念图**：用节点和带动词的连线表达因果、组成或约束关系。
- **一分钟反思**：做得好、出错处、错误原因、下次策略各写一句。
- **赛后复盘**：重建判断过程，而不只记录最终得分。

## 7. LLM agent 模式

### 苏格拉底教练

先收集学习者答案和信心，再追问理由、证据、反例和边界。一次只给最小提示，随着失败逐步增加支架。

### 开放答案评分员

使用明确评分量规检查准确性、完整性、推理和表达。指出缺失成分并让学习者亲自修订到达标。

### 变式与对比生成器

围绕同一深层结构生成表面不同的题目，并混入近邻概念。对生成内容进行学科核验，防止错误题目污染练习。

### 情境模拟器

扮演顾客、患者、对手、角色或环境，根据学习者决策改变后续情节。结束后回放关键决策点并要求反思。

### 间隔调度员

保存目标、上次表现、错误类型、信心和下次复习日期。新会话先检索旧内容，再进入新材料。

### LLM 防替代规则

- 答案在学习者尝试后出现；
- 提示逐级展开；
- 关键步骤由学习者完成；
- 模型反馈说明依据；
- 事实、评分和生成题目可被复核；
- 保留延迟测验，不用对话流畅度代表学习。

## 8. 图像、音频与视频模式

- **遮挡图**：遮住标签、步骤或关键区域，要求识别和重建。
- **对比图组**：并列易混对象，让学习者标记决定性差异。
- **动作分镜**：打乱关键帧，要求排序、解释和预测下一帧。
- **无声视频预测**：在关键点暂停，先预测动作或结果，再播放反馈。
- **口头自由回忆**：录音回答问题，之后按量规自评或由系统反馈。
- **听辨练习**：随机混合发音、语调、节奏或信号类别，要求辨析。

观看和聆听主要提供输入；在其后安排生成、检索或决策，才能形成主动学习。

## 9. 应用与脚本模式

适合自动化的功能包括：

- 从结构化知识库生成题目和变式；
- 打乱顺序并维持题型配比；
- 实现间隔排程和通知；
- 记录作答、提示、信心和延迟表现；
- 根据错误类型选择下一题；
- 生成教师或家长可读的薄弱点报告；
- 运行 A/B 小试点，比较不同练习设计。

最小数据模型通常包括：学习目标、题目、正确答案或量规、混淆项、难度、上次表现、信心、提示级别、下次复习时间和迁移标签。

## 10. 最小试点与评估

先做一个足以暴露设计问题的小试点：

1. 选择三个至五个学习目标；
2. 为每个目标设计首次练习、间隔复习和迁移题；
3. 找出学习者实际如何理解界面和反馈；
4. 记录即时正确率，但不据此下结论；
5. 在延迟后复测，并加入未见题；
6. 比较主观信心和实际表现；
7. 根据错误模式修改内容、间隔或支架。

试点完成标准：能够回答“什么被学会、保持了多久、能否迁移、学习者在哪一步失败、技术是否比简单方案增加了价值”。
