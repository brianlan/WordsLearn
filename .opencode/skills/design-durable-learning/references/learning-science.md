## 1. 学习的目标层级

用以下层级共同评价学习，练习时正确率只是即时表现：

1. **保持**：间隔后仍能记住。
2. **提取**：缺少原始材料时仍能主动想起。
3. **辨析**：能判断当前问题属于哪一类。
4. **应用**：能在熟悉情境中正确使用。
5. **迁移**：能在未见过的情境中调整并使用。
6. **自动化**：在时间或压力有限时仍能快速、可靠地执行。

事实知识与高层次思考并非对立。熟练的基础知识减少工作记忆负担，为分析、判断和创造提供材料。

## 2. 学习的记忆机制

### 编码

首次接触信息形成初步的心理表征。听懂、看懂和流畅阅读说明信息当前可用；延迟检索负责验证长期学习。

### 巩固

记忆痕迹在数小时或数天内被稳定、组织并连接到已有知识。时间、再次思考和睡眠有助于巩固。已有知识越丰富，新知识可连接的结构越多。

### 检索

从长期记忆中重建知识会强化记忆本身和通往它的线索。检索既是测量，也是学习事件。

### 再巩固

检索使记忆重新具有可塑性。随后的反馈、细化和新经验可以修正、更新并强化它。

### 遗忘与线索

遗忘经常是检索线索变弱或受到竞争，不一定是知识痕迹彻底消失。相关背景和线索可以唤醒旧知识；学习新规则有时需要抑制或重新分配旧线索。

## 3. 核心方法的作用与边界

### 检索练习

作用：强化保持、检索路径和元认知校准，并能支持迁移。

强度由认知动作决定：自由回忆、简答、解释和执行通常比辨认型选择题要求更多重构，但任何真实检索都有价值。

边界：在答案出现前完整作答。把重读、抄写或看题后的熟悉感留作输入体验，而用实际作答验证检索。

### 间隔练习

作用：允许巩固和少量遗忘，使后续检索需要从长期记忆中重建。

边界：间隔过短会退化成工作记忆中的重复；过长会退化成重新学习。根据材料、学习者和成功率调整，而非机械使用固定天数。

### 穿插练习

作用：练习问题分类、特征辨析和策略选择。它尤其适合容易混淆的概念、题型、病例、语法形式或动作方案。

边界：学习者至少要对各类问题有初步理解。完全陌生的材料过早混合可能只增加混乱。

### 多样化练习

作用：通过改变相关条件，建立更灵活的心理表征和更丰富的应对方案。

边界：变化要服务于真实使用。无关的界面装饰、噪声或额外步骤只会增加外在负荷。

### 生成

作用：在答案出现前尝试预测、补全或解决问题，激活先验知识，暴露知识缺口，为答案建立检索路径。

边界：允许错误，但必须有纠正性反馈。高风险技能应在模拟或有监督环境中生成，而非让错误直接造成现实伤害。

### 细化

作用：通过自己的语言、因果解释、类比、图示、实例和反例，把新知识连接到已有结构。

边界：类比只能强调相关结构；同时指出类比在哪些地方失效，以免建立错误模型。

### 反思

作用：将经历变成检索、细化、生成和心智演练的复合练习。

高价值问题包括：发生了什么、我如何判断、哪里有效、哪些证据支持、下次如何调整、条件变化会怎样。

边界：只表达感受或复述过程不足以产生完整反思。

### 反馈

作用：纠正错误、补足解释并校准信心。

即时反馈适合安全关键、初学者容易固化错误或无法自我诊断的任务。略微延迟的反馈可让学习者先完成独立重构，减少对外部纠正的依赖。选择应依据风险和支架需要。

### 助记手段

缩写、图像、韵律和记忆宫殿能组织随机信息并提供检索入口。另行安排解释、辨析和迁移任务来建立理解。

## 4. 合意困难

一个困难同时满足以下条件时才有学习价值：

- 直接训练目标能力；
- 学习者通过努力有合理成功机会；
- 迫使其编码、检索、辨析、生成或调整；
- 可以获得有效反馈；
- 情绪和时间成本可承受。

“越难越好”是错误概括。合意困难位于当前能力略上方，而不是远离能力范围。

常见合意困难：少量遗忘后的闭卷回忆、相似题型混合、变化条件、讲解前尝试、逐渐撤除提示、真实但安全的模拟。

常见不合意困难：无法理解的语言、与目标无关的干扰、严重时间压力、羞辱性测验、信息过载、没有反馈的错误练习。

## 5. 常见假象与错误设计

### 熟悉感假象

反复阅读和高亮让材料处理更流畅，但流畅不等于可以独立生成。

### 集中练习假象

连续练同类题会快速提高当下正确率，但变化条件或延迟后可能迅速下降。这是暂时表现优势，不是持久学习证据。

### 技术复杂度假象

应用、视频、AI和游戏通过承载有效认知动作来改善学习；技术形式本身只是媒介。

### 题量假象

大量重复同一模板可能只训练动作惯性。题目需要间隔、混合、变化和选择，才能支持辨析与迁移。

### 经验假象

经历在经过反馈和反思后转化为学习；单纯重复经历容易固化原有习惯。

### 高分假象

开卷提示、固定顺序或即时重复可能抬高练习分数。评估时应加入延迟、撤除提示和未见情境。

## 6. 情绪、错误与成长

错误是反馈信息，不是能力标签。错误尝试之后获得纠正，通常比直接得到答案更能支持学习。

对失败的恐惧会占用有限的工作记忆，使学习者把资源用于监控自我表现。低权重、规则透明、可重复的测验更容易形成安全的检索环境。

向学习者说明困难是学习的一部分，并让其看到策略改变带来的进步。对儿童保持挑战、选择权、休息和支持之间的平衡，以低威胁、可退出和可获得帮助的方式设置困难。

## 7. 从知识到心智模型

重复的费力检索、变化条件和真实应用，会把相关事实、判断和动作整合成心智模型。心智模型使人能够：

- 快速识别情境；
- 选出适当策略；
- 预测结果；
- 在变化中调整；
- 在时间有限时自动执行。

训练应尽可能反映未来知识的使用方式。“知道什么”和“怎样使用所知”都需要练习。

## 8. 设计判断表

| 目标 | 首选机制 | 关键检验 |
| --- | --- | --- |
| 词汇、事实、符号 | 检索 + 间隔 | 延迟后无提示回忆 |
| 程序步骤 | 检索 + 渐隐支架 + 模拟 | 脱离清单完整执行 |
| 概念理解 | 生成 + 细化 + 反例 | 自己解释并预测新例子 |
| 相似类别辨析 | 穿插 + 对比 + 反馈 | 对未见样例正确分类 |
| 解题策略选择 | 穿插 + 变化 + 反思 | 先识别问题再选方法 |
| 运动或专业技能 | 间隔 + 多样化 + 真实模拟 | 在变化和压力下可靠执行 |
| 迁移 | 多样化 + 模拟 + 反思 | 未见情境中调整应用 |
| 校准 | 信心预测 + 闭卷测验 + 延迟复测 | 主观信心接近实际表现 |
